# Sprint 07 — Recursos clássicos restantes

## Objetivo

Implementar somente funcionalidades cujo comportamento clássico tenha sido documentado depois do levantamento inicial.

## Regra principal

Antes de iniciar esta Sprint, revisar `SPECIFICATION.md` e `COMMANDS.md` para localizar itens `TBD`.

Nenhum item TBD deve ser preenchido por suposição.

Possíveis áreas, dependendo do levantamento disponível:

- busca;
- substituição;
- semântica completa de `F3 L`, `F3 W`, `F3 C`;
- detalhes finos de Word Wrap;
- demais atalhos de ajuda ainda não registrados.

## Critério de aceite

A Sprint só é considerada fechada para os recursos efetivamente especificados e testados.
